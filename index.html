About

Learning by shipping full systems, not just features.

I'm a 3rd-year BSc (Hons) Information Technology undergraduate at the Sri Lanka Institute of Information Technology (SLIIT), with hands-on experience building full-stack web applications using the MERN stack, PHP, and Java EE — and native Android apps with Kotlin.

I care about the parts of a system that are easy to skip: conflict-detection logic in a booking engine, role-based access control in an admin panel, offline-first data persistence on mobile. Most of my projects have been built with small teams under real deadlines, which is where I've learned the most about MVC architecture and REST API design.

  • Proficient in RESTful API development, database design, and MVC architecture
  • Currently sharpening: Advanced Java, Web Development & System Design
  • Interested in: Full-Stack Development & AI
  • Goal: become a skilled Software Engineer
